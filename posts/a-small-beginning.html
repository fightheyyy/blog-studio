留一小块地方，放自己做过的事

一个名字，两行介绍，几个项目，再加上慢慢写下来的文章。这个博客就从这里开始。

2026.09.01 约 4 分钟阅读

这是模板里的示例文章。你可以保留它的排版，换上自己的文字，也可以删掉它，重新写第一篇。

先把首页改成你的

在 Studio 左侧打开「首页与站点设置」。名字可以分成实心和描边两部分；下面的两段介绍，一段说你在做什么，另一段留给你想补充的话。

项目不必很多。选一件已经能打开、能看懂的东西，写清楚它是什么，再放上链接。代码仓库、演示页面和一篇相关的记录，可以放在同一个项目里。

再写一篇小文章

新建文章后，填上标题和 Slug。标题可以分行，Slug 会成为网址的一部分。正文可以在右侧直接编辑，复杂的排版可以切换到 HTML。

保存到本地之后

文章会出现在首页索引里。下次构建或发布站点时，所有已保存的文章都会包含在内。暂时不想公开的笔记，请放在仓库外面。

让别人也能读到

本地写作只需要两个命令：

npm ci
npm run studio

写好后运行 npm run build，把生成的 dist/ 交给静态托管服务。使用 GitHub Pages 的话，项目里已经有构建工作流，具体步骤放在 README 中。

这个页面的字体、留白和分隔线都在模板里。你只需要决定第一篇写什么。
